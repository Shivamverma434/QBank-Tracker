# 📚 QBank Tracker

A web app to track your question bank practice sessions, accuracy, and all-time trends.

## Features

- **📊 Overview Dashboard** — See total questions attempted, correct answers, overall accuracy %, and current day streak at a glance
- **➕ Log Sessions** — Record any study session with subject/topic, total questions, correct answers, and optional notes
- **📈 All-Time Trends** — Bar + line chart showing questions attempted and accuracy % over time
- **📝 Session History** — Browse and delete all past sessions with per-session accuracy rings
- **🏷️ Subject Breakdown** — Progress bars per subject showing accuracy and question counts
- **💾 Persistent Storage** — All data is stored locally in your browser (localStorage)

## Tech Stack

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/) — build tool
- [Tailwind CSS v3](https://tailwindcss.com/) — styling
- [Recharts](https://recharts.org/) — trend charts

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```
